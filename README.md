# PDF Manager

[English](README.en.md) · 繁體中文

> **v2.11.0-F**：頁內文字工具列、復原／重做、未匯出提醒、來源批次載入失敗保護及可取消 PDF／ZIP 匯出。

### 來源載入與可取消匯出

- 右側來源整批成功才替換；其中一份 PDF、圖片或 DOCX 失敗時，原來源、選取及主文件均保留，錯誤提示標示失敗檔案在批次中的順序。不再默默略過不支援格式、多份 DOCX 或轉換失敗的 DOCX 頁面。
- PDF／ZIP 匯出可按「取消匯出」或 Esc；在頁面之間與下載前檢查取消，不產生部分下載、不清除編輯、不標記為已匯出。單頁轉換、資源清理或 ZIP 打包期間須等待目前步驟完成，並非立即中斷。
- 匯出進度提供讀屏語意、鍵盤可聚焦的取消按鈕；匯出成功後仍需確認下載檔已存妥。來源載入期間禁止重複載入／匯出。
- 僅使用本機合成測試；120 頁純文字 PDF 的頁數、首尾文字與順序驗證通過，不代表已完成超大圖片文件壓力測試。

### 穩定性與工作流程打磨

- 新增重做（Ctrl+Shift+Z／Ctrl+Y），主畫面與頁面編輯器皆可使用。點選物件、沒有修改的文字不占復原步數；一次拖曳只算一步。
- 顯示尚未匯出的修改；更換主文件前確認，關閉／重新整理時由瀏覽器提醒。新文件解析成功後才替換，讀取失敗保留原工作階段。
- PDF／ZIP 匯出使用固定快照，處理期間鎖定操作並拒絕重複匯出；失敗後解除鎖定、保留修改。
- 文字框即時顯示字數、草稿狀態及格式／超頁錯誤；工作區隨視窗寬度調整，工具列可捲動，不再透出背後主畫面。

**提醒不等於自動儲存。** 產生下載不代表瀏覽器已成功存檔，請自行確認下載結果。編輯中的文字／表格資料仍只在本次工作階段；未加入雲端上傳或背景保存。本版本不代表已完成商用安全認證或全瀏覽器相容性驗證。

> 本版包含原 v2.9.0-F 審閱版的頁內文字編輯：新增文字直接在頁面輸入，工具列提供字型、字級、顏色、粗體、斜體、底線、對齊、行距與框寬。

### 文字操作

按「加入文字」即可在頁面文字框輸入；雙擊已新增的文字可重新編輯。格式套用整個文字框，尚不支援同框內局部文字混合格式。Ctrl+B／I／U 切換粗體／斜體／底線；Ctrl+Enter 套用，Esc 取消本次修改。切換工具或按頁面編輯器「完成」也會先套用文字；完成後可拖曳移動及縮放。

字型使用本機已安裝字型，缺少時由瀏覽器替代，不下載或附帶字型。新增文字匯出仍會定稿為圖片；不直接修改原 PDF 文字。表格仍使用原有儲存格編輯器。文字超出頁面時會阻擋套用，不悄悄縮小字級或裁掉內容。

> **v2.8.1-F**：新增文字、剪貼簿圖片及可編輯表格功能；修正普通超連結阻擋消去，拒絕訊息顯示主 PDF 頁碼與原因。新增內容匯出後定稿為圖片。

### 頁面編輯

- 左側選取一頁後按「編輯頁面」，或雙擊該頁；用 Ctrl+V 貼上圖片、表格或文字。剪貼簿按鈕可能需要瀏覽器權限。
- 新增文字／表格可移動縮放；雙擊物件修改內容。表格可編輯儲存格並增刪列欄，不會把既有 PDF 表格還原為儲存格。
- 「框選消去」會真正替換該頁來源內容，**只有編輯頁轉成圖片**，其他頁仍保留文字。操作前會確認，工作階段內可復原；原始檔案不會覆寫。
- 自製資源清理會移除未使用的共用資源與不可達物件；整份 PDF 和 ZIP 分頁輸出都會清理。若另一頁仍使用原始圖片、或文件含不支援的結構，會拒絕操作／輸出，而不是改動其他頁。
- 未編輯頁的普通 HTTP(S)／mailto 網址及明確目的頁的內部超連結不再阻擋消去，輸出時安全重建。編輯頁的連結隨頁面圖片化移除；連到該頁的跳頁連結保留。目的頁被刪除或不在分頁 ZIP 中時，移除該跳頁連結，不把原頁偷偷帶入輸出。
- 暫不支援含表單、簽章、其他註解、JavaScript／附加動作、具自訂外觀或無法解析目的地的連結、圖層、內嵌圖片（BI）、Type3 字型及部分圖樣／著色／軟遮罩的消去。錯誤會顯示主 PDF 頁碼與具體類別；文件層級問題顯示「文件」。此功能不是全文件個資清理。
- 沒有整合 MuPDF／EmbedPDF／PDFium，也沒有新增 AGPL 依賴；現有第三方授權聲明保留。自有程式碼正式開源授權仍待選定。

本專案提供瀏覽器基底之以頁面為基礎用來整理、合併 PDF 的工具，不必把文件交給線上轉檔服務。

目前版本：**v2.11.0-F**。介面支援 **繁體中文 / English**，並提供四套可切換佈景。

本版新增頁面內容編輯與有限範圍的框選消去，並保留先前旋轉 PDF 蓋章座標修正。

## 能做什麼？

- **整理頁面**：刪除、拖曳排序、整組移動、旋轉，以及最多 30 步復原。
- **插入內容**：從其他 PDF、圖片或 DOCX 加入頁面；支援來源多選及整組拖入。
- **合併頁面**：把多個來源頁垂直拼貼為單頁。
- **加入印章**：載入圖片或 PDF 印章，移動、縮放、翻轉與矩形裁切。
- **編輯頁面**：新增文字、貼入圖片與表格、編輯表格儲存格及列欄，並對支援的文件框選消去。
- **輸出檔案**：另存整份 PDF，或逐頁輸出 PDF 並打包 ZIP。
- **調整工作介面**：中英文即時切換、三段縮圖尺寸、可拖曳面板寬度，以及四套佈景。

本工具可新增文字，但尚不能直接修改既有 PDF 文字，也不含 OCR 或數位簽章服務。圖片蓋章功能僅為覆蓋圖片，不等於具驗證能力的數位簽章。

## 快速開始

離線版請到 [v2.11.0-F 下載頁](https://github.com/Teafox113/PDF_manager/releases/tag/v2.11.0-F)，下載 `pdf_editor_offline_v2.11.0-F.html` 後以桌面版 Chrome／Edge 開啟。

1. 下載或複製專案，用桌面版 Chrome 或 Edge 開啟 [pdf_editor.html](pdf_editor.html)。
2. 在工具列選擇 **Language / 語言** 與 **佈景 / Theme**。
3. 按「開啟主 PDF」，需要插入內容時在右側開啟來源檔案。
4. 整理完成後按「另存新檔」下載結果。修改不會直接覆寫原文件。

來源版每次啟動都可能需要網路載入固定版本的 CDN 函式庫；不保證開啟過一次就能永久離線。文件編輯狀態不會自動儲存，關閉或重新整理前請先下載結果。

## 語言與佈景

語言切換會更新工具列、選單、提示、狀態、確認視窗及蓋章介面；不翻譯文件內容或使用者檔名，也不重設頁面與復原紀錄。預設為繁體中文。

| 佈景 | 配色與風格 |
| --- | --- |
| 鈦金深色 / Titanium | 暖黑底、香檳金重點（預設） |
| 紙感淺色 / Paper | 白色工作區、霧灰底、墨藍重點 |
| 深海藍 / Ocean | 深藍工作區、冰藍重點 |
| 森林綠 / Forest | 深綠工作區、鼠尾草綠重點 |

瀏覽器允許時會記住語言、佈景與面板寬度；停用儲存功能時仍可使用，只是不保留偏好。主題不改變 PDF、印章或輸出檔案的顏色。

## 建立離線版

需求：**Python 3.10 或更新版本**，以及建置時的網路連線。不需要 npm 安裝步驟。

在專案根目錄執行：

```sh
python build_offline.py
```

產出：

```text
release-assets/pdf_editor_offline_v2.8.1-F.html
```

直接用瀏覽器開啟此檔即可使用離線版。建置會核對函式庫及授權檔雜湊、內嵌依賴及完整第三方條文；同名成品存在時停止，不自動覆寫。離線 HTML 不納入 Git 歷史，透過 GitHub Release 附件提供下載。

## 隱私與資料

- 應用程式在瀏覽器本機解析、編排與輸出文件，沒有設計文件上傳 API。
- 來源版會向 cdnjs 請求 JavaScript，這不等同文件上傳，但來源版不是完全離線執行。
- 離線成品內嵌函式庫，使用內容安全政策限制外部連線。
- `localStorage` 只保存介面偏好，不保存文件內容。
- 處理機密資料時，應使用經驗證的離線成品並遵循所在組織的資料規範。功能測試不等於全面資安稽核。

## 限制

- 舊式 `.doc` 不支援；DOCX 轉換不保證保留 Word 原始排版。DOCX 不支援與 PDF／圖片混合批次載入，多個 DOCX 同時選取時只處理第一個。
- 密碼保護、特殊加密或結構異常 PDF 不保證可讀取。
- 旋轉 PDF 頁面會轉成約 1200px 寬點陣圖，可能失去文字選取能力及增加檔案大小。
- 大型文件、圖片與復原快照可能占用大量記憶體。
- 主要以桌面瀏覽器操作為目標；Firefox、Safari 與手機介面尚未完整驗證。
- 第三方函式庫沿用固定版本，本次未進行全面依賴漏洞稽核；請勿把未知來源檔案視為可信。

## 測試與問題回報

```sh
python -m unittest discover -s tests -v
```

開發用瀏覽器測試另需 Node.js、Playwright 與 Chrome，且先完成離線建置：

```sh
npm install --no-save --package-lock=false playwright
node tests/test_ui.cjs
```

Node.js / Playwright 僅用於測試，不是使用或打包工具的必要依賴。詳見 [實測報告](docs/TEST_REPORT.md) 與 [已知限制](docs/KNOWN_ISSUES.md)。

回報問題時請提供版本、瀏覽器、操作步驟及去識別化截圖；勿公開上傳個資、內部 PDF、印章原檔或憑證。
