PDF 頁面編輯器 v2.2.0-F（branch_v2 分枝）
本版本功能
開啟主 PDF · 頁面縮圖預覽（三段縮放，懶渲染）· 刪除頁面 · 拖曳重排（支援多選整組） · 多頁上移 / 下移 / 移到最前最後 · 批次選取（全選 / 反選 / 奇偶頁 / 頁碼範圍 / Ctrl+A） · 插入來源頁面（PDF / JPG / PNG / WEBP / GIF / BMP，左側以冰鈦藍截角標示）· 右側縮圖拖曳到左側插入 · 右側多檔批次載入（PDF + 圖片混合）· 右側來源全選 · 縮圖旋轉（↺ ↻，支援 Undo） · 右側選取複數頁合併為左側一頁（垂直拼貼，A4 寬度）· 左側無 PDF 亦可直接合併 · DOCX 分頁預覽（Mammoth.js）· 另存新 PDF · 個別分頁 ZIP 存檔 · Undo 復原（最多 30 步 / Ctrl+Z）· 檔案拖曳開啟
v2.2.0-F 變更內容
新增「個別分頁」輸出：可將左側所有頁面各自存成 PDF，依輸入檔名自動加 01/02/03 編號並打包為 ZIP
v2.1.4-F 變更內容
左側縮圖新增冰鈦藍右下截角，標示由右側來源插入或合併產生的頁面
更早版本變更請見 CHANGELOG 檔案（About 僅保留最近 2 版）
