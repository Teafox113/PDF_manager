# 文件索引

- `PROJECT_INDEX.md`：專案架構與功能概況
- `FUNCTION_MAP.md`：主程式函式索引
- `KNOWN_ISSUES.md`：目前限制與已知問題
- `TEST_REPORT.md`：功能測試清單與結果
- `TASK_CHECKLIST.md`：開發任務狀態
- `DEV_LOG.md`：完整開發日誌
- `VERSION_WORKFLOW.md`：版號與建置流程
- `BRANCH_EVALUATION.md`：branch_v2 起點評估
- `CHANGELOG_v*.md`：各版本詳細變更

本資料夾包含歷史文件。發布首頁與最新使用方式以根目錄 `README.md`、`CHANGELOG.md` 和 `version.json` 為準。
