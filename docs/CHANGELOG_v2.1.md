## v2.1.2-F — 2026-06-11

### 臭蟲修正
1. **110% 縮放後底部功能區被擠出畫面**（使用者回報）
   - 原因：`zoom: 1.1` 連同 `height: 100vh` 一起放大，body 實際高度變成
     視窗的 110%，底部 10%（狀態列、右下「插入到主 PDF」「合併」按鈕區）超出可視範圍
   - 修正：`height: calc(100vh / 1.1)`，zoom 後恰好填滿視窗
   - 備註：日後若調整 zoom 倍率，calc 分母需同步修改（CSS 內已留註解）


## v2.1.1-F — 2026-06-11

### UI 微調
1. **全介面預設放大 110%**（使用者要求，等同 Ctrl+滾輪放大一格）：
   `body { zoom: 1.1 }`，所有字型、按鈕、縮圖、間距等比放大
2. **分隔線座標校正**：zoom 之後滑鼠座標（視覺 px）與版面寬度（layout px）相差
   1.1 倍，splitter 的 mousemove / clampW / resize 計算除以 `UI_ZOOM`
   （自動讀取 computed zoom，日後改縮放比例不需動 JS）

### 備註
- 使用者仍可 Ctrl+滾輪在 110% 基礎上繼續縮放
- zoom 屬性 Chrome/Edge 完整支援（專案目標瀏覽器），Firefox 126+ 支援


## v2.1.0-F — 2026-06-11

### 新功能

#### P9-3 可拖曳分隔線
1. 左右面板之間新增 7px 寬拖曳熱區（`#splitter`），中央顯示鈦金橙握把指示，
   hover / 拖曳時加亮
2. 拖曳即時調整右側面板寬度，範圍限制：最小 220px ～ 最大視窗寬 60%
3. **雙擊分隔線重設**為預設 320px
4. **寬度記憶**：localStorage 保存（`pdfEditorRightW`），下次開啟自動還原；
   file:// 或隱私模式下 localStorage 不可用時靜默略過，不影響功能
5. **視窗縮放防呆**：resize 時若右側佔比超限自動夾回範圍

### 技術備註
- 左面板改 `min-width: 0` 防止 flex 內容撐爆；原 border-right 移至 splitter 中心線
- CSP 不受影響（無外部資源）；離線版打包流程不變
