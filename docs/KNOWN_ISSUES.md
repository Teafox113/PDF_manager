# 已知問題（v2.8.1-F）

## v2.11.0-F 本機候選（2026-10-19）

- 匯出取消為安全檢查點機制：單頁轉換、清理與 ZIP 打包等正在執行的步驟不能立即中斷，可能需要等待。瀏覽器嚴重缺乏記憶體時仍可能無法回應。
- 來源載入尚不能取消，但失敗會保留原有來源。舊版 `.doc`、多份 DOCX 及不支援檔案明確拒絕；取代下方舊版「只讀第一份」行為。
- 已通過 120 頁純文字合成測試，並非大容量掃描圖／上千頁／全部密碼與損壞文件驗證。DOCX 失敗路徑測試不代表版面忠實度保證。
- 進度條與取消鍵具基本無障礙語意，尚未完成真實讀屏器驗收。無自動儲存／當機恢復、正式專案授權選定及全面資安稽核等限制不變。

## v2.10.0-F 候選與商用品質後續驗收（2026-10-19）

- 本輪改善可靠性及易用性，不等於已完成商用安全認證。尚待 Firefox／Safari、實體觸控裝置、大型／特殊 PDF 壓力測試、實際中文輸入法與完整無障礙驗收。
- 無自動儲存／工作階段恢復。未匯出提醒依目前文件版本與草稿判定；beforeunload 提示由瀏覽器決定是否顯示，不能保證在當機、強制關閉或行動裝置關閉程序時出現。
- 匯出後只知道已產生下載，不能偵測使用者取消下載或磁碟寫入失敗；仍須人工確認檔案。匯出 PDF 仍不能還原本工具可編輯的文字／表格資料。
- 字體、既有 PDF 文字編輯、局部富文字、OCR 及有限消去支援範圍延續下方說明。未新增第三方套件，也未完成全面依賴漏洞與正式授權選定工作。
- 復原／重做合計最多 30 步；大文件與圖片的記憶體壓力仍需評估。文件載入／匯出鎖定不等於支援背景併行工作。

## v2.9.0-F 本機候選文字限制（2026-10-19）

- 文字在頁面上直接輸入，但格式套用整框，尚無局部選字混合格式、項目符號、跨頁排版或拼字檢查整合。
- 原 PDF 文字不能直接編輯；新文字輸出後為圖片，重新載入 PDF 不會還原可編輯文字框。表格仍為對話框編輯。
- 字型依使用者系統安裝情況替代；未附帶或下載字型。中文輸入法已測組字鍵盤事件隔離，仍需使用者用實際輸入法驗收。
- 文字框字級 8–72、文字最多 10000 字，超出頁面或處理上限拒絕套用；不自動縮字或整份頁面圖片化。已縮放／裁切的舊文字框重新編輯會重新排版、清除翻轉／裁切。

## v2.8.1-F 修正與現行超連結範圍

- 普通 HTTP(S)／mailto 及明確陣列目的地的文件內跳頁連結已支援，不會阻擋其他頁消去；下方 v2.8.0-F 全面禁止註解的敘述屬舊限制。
- JavaScript、附加動作 Next／AA、自訂外觀 AP、無法解析的具名目的地及其他註解仍拒絕。訊息包含主 PDF 頁碼與原因，不顯示實際連結或文件內容。
- 消去頁上的連結隨該頁定稿移除；跳往該頁的其他連結仍可用，但目的地改為整頁適配。被刪除或不在 ZIP 分頁檔中的目的地連結會省略。
- 私人樣本的瀏覽器字型模式逐像素比對曾出現少量差異；字形輪廓渲染模式下所有未編輯頁像素一致，文字擷取亦一致。不將不同字型渲染路徑的像素差異當成內容遺失，也不宣稱已查明瀏覽器字型差異的全部原因。

## v2.8.0-F 未發布候選限制（2026-10-16）

- 消去改為單頁圖片化加自製資源清理；未編輯頁文字保留。清理器對不支援語法／結構直接拒絕，不嘗試猜測或自動整份圖片化。
- 跨頁仍在使用的原始圖片（含圖片遮罩、原頁資源中的圖片）會保守拒絕；即使只是相同圖片位元組也可能拒絕。不會為了消去一頁而刪掉另一頁圖片。
- 含表單、簽章、註解、圖層、內嵌圖片 BI、Type3 字型、使用中的圖樣／著色／具名屬性、ExtGState 軟遮罩、未知操作符或頁面／Form 額外欄位等，尚不支援消去。單一內容串流上限 8 MB、累計內容／輸出上限 40 MB、遞迴 64 層；大型文件可能被拒絕。
- 消去不是全文件敏感資訊清理；其他頁既有重複文字不會自動刪除。新增物件與未消去區域在該頁均定稿為圖片。無法承諾對任意 PDF 的安全性，敏感文件仍應人工核對。
- EmbedPDF PDFium 2.15.1 直接消去在合成案例中連帶清除其他頁共用圖片，尚不能直接整合。
- MuPDF 1.28.1 的評估結果僅留歷史參考，本候選版不整合，也不分發其程式碼或二進位檔。
- 只新增文字／表格，不可修改原有 PDF 文字或將原有表格還原成儲存格。新增內容匯出後為圖片，不可搜尋；原有文字不因此圖片化。
- 剪貼簿表格保留文字及儲存格結構，不保證原格式；合併儲存格展開；最多 60 列、20 欄，每格 2000 字。
- 新功能目前僅初步 Chrome 離線測試；剪貼簿按鈕受瀏覽器權限限制，可改用 Ctrl+V。

## v2.7.1-F 修正

- 已修正旋轉目標 PDF 的印章隱形邊界、縮圖比例與輸出位置不一致，並處理偏移 CropBox。
- 不會把目標 PDF 點陣化；工具列「旋轉頁面」仍有下述 K06 限制。
- 本次不擴充 PDF 印章來源本身的旋轉／裁切框相容性；複雜來源仍需核對輸出。
