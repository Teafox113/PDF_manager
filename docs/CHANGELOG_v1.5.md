# CHANGELOG v1.5（branch_v2 / Fable 開發線）

## v1.5.1-F — 2026-06-11

### 臭蟲修正
1. **左側拖曳重排誤觸「拖曳 PDF 至此開啟」**（使用者回報）
   - 原因：Chromium 拖曳含 `<img>` 的縮圖卡片時，`dataTransfer.types` 會自動
     附帶 `'Files'`；左側空白區 dragover 把 Files 檢查放在最前，內部重排
     被誤判為外部檔案拖入。放開在空白區時甚至會把縮圖圖片誤載為主檔
   - 修正：以全域 `dragMode` 旗標優先判斷內部拖曳——
     重排懸停空白區不顯示讀檔覆蓋層、放開改為取消動作；
     src-insert 與 Files 分支順序重排；右側面板加上同樣防護
   - 影響函式：`left-thumbs` 與 `right-thumbs` 的 dragover / drop 處理器


## v1.5.0-F — 2026-06-11

### 新功能

#### P8-D 批次選取工具
1. 工具列新增「☑ 選取 ▾」下拉群組（避免按鈕扁平堆積）：
   全選（Ctrl+A）、反選、奇數頁、偶數頁、頁碼範圍
2. 頁碼範圍輸入做在 Modal 內（新增 `showInputModal()`），支援格式：
   `1-5, 8, 10-12`（逗號/頓號/空白分隔，`-` `~` 皆可表示範圍，超界自動忽略）
3. 狀態列即時顯示「已選 n 頁」

#### P8-A 多頁操作補完
4. `movePage()` 重寫：選取多頁可整組上移/下移/移到最前/最後，保持相對順序
5. 多選拖曳重排：拖曳已選取的卡片時整組移動，往下拖放在目標卡之後、
   往上拖放在目標卡之前；落點選取自動跟隨
6. 修正原版 drop 處理器中選取狀態的無效程式碼（clear 後再查詢的死邏輯）

#### P8-B 大檔效能
7. 縮圖懶渲染：IntersectionObserver（rootMargin 300px），卡片進入可視範圍
   才執行 PDF/圖片渲染；100+ 頁大檔開啟與重排不再全量渲染
8. 卡片移除時同步 unobserve，避免 observer 持有已移除節點

### 流程改良
9. 建立 `backups/` 改版前備份制度（詳見 VERSION_WORKFLOW.md）：
   改 pdf_editor.html 前先備份現行版本，失敗可立即還原
10. About 面板新政策：僅保留最近 2 版變更說明，舊版移至 CHANGELOG
11. 新增 `FUNCTION_MAP.md` 函式索引，降低開發時的全檔讀取成本
