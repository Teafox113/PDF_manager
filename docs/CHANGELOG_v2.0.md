## v2.0.0-F — 2026-06-11

### 性質
介面大改版（依版號規則升 MAJOR）。功能與 v1.5.1-F 完全相同，所有變更為視覺層。

**鈦金屬 × 低調質感 × 線性符號**。

#### iOS 質感處理
1. **毛玻璃**：工具列 / 選取選單 / About / Toast / 進度框 → 半透明 + backdrop-blur
2. **膠囊按鈕**：全按鈕 border-radius 999px；主按鈕垂直微漸層 + 深色文字；
   危險/儲存改 iOS 半透明色塊風格；按下 scale(.97)
3. **髮絲線**：邊框統一 0.5px rgba 暖白
4. **縮圖卡片**：12px 圓角、170° 微漸層底、選取 = 鈦金橙邊框 + 光暈環
5. **噪訊紋路**：body::after 內嵌 SVG feTurbulence，透明度 2.2%（低調），
   data URI 不增加外部請求、與 CSP img-src data: 相容
6. **插入指示線 / 選取順序徽章**：鈦金橙（操作回饋醒目）；資訊性元素香檳金（沉穩）

#### 圖示
7. emoji 全面替換為 Unicode 線性符號：
   ⊕ 開啟 · ✓ 選取 · ✕ 刪除 · ↑↓↟↡ 排序 · ⌕ 縮圖 · ⤓ 另存/拖放 · ＋ 插入 · ⧉ 合併
   （含 JS toast 訊息與動態按鈕文字）
